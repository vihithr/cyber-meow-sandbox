## 🌟 核心特色与功能

### 1. 🐱 灵动猫咪生态与行为树系统 (`js/cat.js`)
- **多品种与外貌**：
  - 🍊 **大橘（橘猫）**：经典虎斑条纹，吃货属性。
  - 🥛 **奥利奥（奶牛猫）**：黑白面具，跑酷狂魔，精力无限。
  - 🐘 **英短蓝猫**：圆润大脸盘，沉稳庄重。
  - ❄️ **雪球（纯白异瞳）**：蓝黄双色异瞳，仙气灵动。
  - 🎨 **三花猫**：俏皮斑块，好奇心爆棚。
  - ☕ **暹罗猫**：重点色温控体征。
- **动态骨骼与拟真面部动力学**：
  - **Verlet 5 节段物理猫尾**：随移动与情绪自然摆荡（开心翘尾、受惊炸毛）。
  - **屁股摇晃扑杀预备**：捕猎前骨骼微弯，屁股左右摇晃 3 次后迅猛飞扑！
  - **动态瞳孔与眼睑**：暗处/捕猎时瞳孔放大如圆宝石，强光下收窄；抚摸时闭眼惬意弯成 `( ^ ᵕ ^ )`。
  - **自主行为树**：巡逻漫步、在阳光下打滚伸懒腰、磨爪子、钻箱子、跳上扫地机。

---

### 2. 🪑 丰富的家具与玩具生态 (`js/furniture.js`, `js/toys.js`)
- 🤖 **智能扫地机 (Roomba)**：自主巡逻避障，猫咪可以跳上去坐着兜风！
- 🌳 **多层豪华猫爬架 (Cat Tree)**：包含多层平台与麻绳立柱，悬挂动态摆动毛球。
- 🪵 **瓦楞纸猫抓板 (Scratcher)**：猫咪定期前往磨爪，伴随真实抓挠摩擦音效。
- 📦 **经典纸箱 (Cardboard Box)**：“只要我塞得下，我就要坐进去”——猫咪会自主钻入并露出小脑袋。
- ☀️ **温暖阳光光斑 (Sunbeam)**：斜照进室内的温暖光束，猫咪聚集在光晕下打盹恢复精力。
- 🪶 **物理羽毛逗猫棒 (Feather Wand)**：跟随光标的物理柔性绳索与彩色羽毛。
- 🔴 **高亮激光红点 (Laser)**：令所有猫咪陷入追逐狂欢。
- 🧶 **高弹毛线球 (Yarn)**：带有物理反弹与彩色拖尾。
- 🐟 **小鱼干 (Fish Treat)**：补充饱腹度与增进感情。
- 🌿 **猫薄荷喷雾 (Catnip)**：全屏彩虹粒子狂欢与极速暴走。
- 🛸 **反重力模式 (Antigravity Mode)**：一键失重，慢动作在空中漂浮翻滚。

---

### 3. 🔊 纯合成 Web Audio 声音引擎 (`js/audio.js`)
- **零外部音频文件**：纯粹使用振荡器、带通/低通滤波器与噪声发生器实时合成！
- **拟真猫咪呼噜声（Purr Engine）**：基于 25Hz 低频调制粉红噪声，还原猫咪喉部共振。
- **多样化猫鸣**：轻柔短促的鸟鸣颤音（Chirp）、撒娇拉长音（Pleading）、捕食咔咔齿音（Chatter）。
- **程序化生成 Lofi 氛围音律**：五声音阶和弦进行，陪伴学习/工作的舒缓背景音乐。
- **物理碰撞与器械音**：磨爪摩擦声、吃鱼咀嚼脆响、扫地机马达嗡鸣、相机机械快门声。

---

### 4. 📇 身份证系统与互动玩法 (`js/ui.js`)
- **猫咪身份证 (Cat Passport)**：
  - 点击任意猫咪唤起卡片，实时渲染头部形象。
  - 支持**自由修改猫咪名字**。
  - 实时监控：饱腹度、亲密度、精力值。
  - 🎩 **专属装扮自由切换**：无配饰、金色铃铛、粉色蝴蝶结、魔法巫师帽、派对彩帽。
- 📸 **拍立得快照 (Polaroid Snapshot)**：
  - 一键拍摄当前温馨瞬间，自动附加拍立得相纸白边、手写签名水印与时间戳，并支持导出 PNG 图片。
- 🎯 **红点追逐 45 秒挑战**：
  - 倒计时引导游戏，操作红点带领猫群扑击金色星星，挑战高分！
- 💾 **本地自动存档**：自动持久化保存当前猫咪成员、名字、性格与装扮。

## 📁 项目工程架构

```text
cyber-meow-sandbox/
├── index.html            # 主界面与 DOM 结构（单文件即开即玩）
├── start.bat             # Windows 一键启动脚本
├── server.py             # 极速本地 Python 开发服务器
├── README.md             # 详细文档
├── css/
│   └── style.css         # 赛博拟物玻璃拟态（Glassmorphism）样式
├── js/
│   ├── physics.js        # Verlet 链式物理、向量数学与世界环境控制
│   ├── audio.js          # Web Audio 声音合成器（呼噜、猫叫、Lofi生成乐）
│   ├── furniture.js      # 扫地机、猫爬架、猫抓板、纸箱、阳光光斑
│   ├── toys.js           # 逗猫棒、毛线球、小鱼干
│   ├── cat.js            # 猫咪智能体（骨骼动画、表情IK、行为树）
│   ├── environment.js    # 日夜主题、雨滴与微尘萤火虫天气
│   ├── ui.js             # 身份证、拍立得快照、挑战小游戏
│   └── app.js            # 核心游戏循环、输入监听与状态协调
└── tests/
    └── verify.js         # 自动化语法与物理逻辑自检测试
```

## 🚀 启动与体验方式

### 方式 A：直接运行（推荐，秒开）
- 双击运行根目录下的 [start.bat](file:///f:/PlayGround/cyber-meow-sandbox/start.bat)。
- 或者直接用 Chrome / Edge / Firefox 双击打开 [index.html](file:///f:/PlayGround/cyber-meow-sandbox/index.html)。

### 方式 B：启动本地 Python HTTP 服务
```powershell
python cyber-meow-sandbox/server.py
```
终端会自动弹出 `http://localhost:8088`，亦可分享给同一局域网下的手机或平板浏览器体验！

### 方式 C：运行自动化测试
```powershell
node cyber-meow-sandbox/tests/verify.js
```
