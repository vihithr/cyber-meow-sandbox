## 🚀 启动与体验方式

### 方式 A：直接运行（推荐，秒开）
- 双击运行根目录下的 [start.bat](start.bat)。
- 或者直接用 Chrome / Edge / Firefox 双击打开 [index.html](index.html)。

### 方式 B：启动本地 Python HTTP 服务
```powershell
python cyber-meow-sandbox/server.py
```
终端会自动弹出 `http://localhost:8088`，亦可分享给同一局域网下的手机或平板浏览器体验！

### 方式 C：运行自动化测试
```powershell
node cyber-meow-sandbox/tests/verify.js
```
当前共 94 项真实断言，失败时以退出码 1 结束。

### 快捷键
`1`–`0` 切换工具，`A/D` 或方向键平移镜头，`空格` 反重力，`M` 全体猫叫，`P` 拍照，**`C` 喵视角**（镜头跟随一只猫，把自己当成猫），**`Q` 手动画质**（高 / 均衡 / 流畅循环）。

画质默认自动：帧间隔连续偏高时自动降 DPR 并跳过昂贵细节，持续流畅后自动恢复。**按过 `Q` 即锁定当前档位，自适应不再回切**——切到「流畅」后就是稳定的 low，方便做性能对照测试。
