## 🌟 核心特色与功能

### 1. 🐱 真正的猫咪智能体与生理心理学 (`js/cat.js`)
- **🧠 8 大猫生战术大计策略引擎 (Tactical Agenda System)**：
  - 👑 **争霸王座 (THRONEC_QUEST)**：不乱跑，锁死豪宅最高跳台/猫爬架顶层发起攀登。若有占座猫，触发飞机耳耸肩对峙决斗（Stare-down Duel），落败者被吓退坠落高台，胜者登基开启**俯瞰蔑视 (Judging Overlook)**，半眯蔑视眼俯视众生！
  - 🎯 **一二三木头人战术潜行 (STEALTH_HUNT)**：尾行受害猫或扫地机。目标回头时立刻像雕像般**石化定格 (Stealth Freeze)**；背对时贴地匍匐蠕动，进入射程后屁股疯狂蓄力摇摆（Butt Wiggle），爆发刺客背刺飞扑！
  - 🥣 **守仓催粮与拍机黑客 (FEEDER_CAMP & HACK)**：贪吃猫径直走向智能自动投喂机端坐死守；若不出粮则站立伸爪物理**拍打敲碗**，高概率震出香脆小鱼干！
  - 😏 **蓄意推物搞事拆迁 (MISCHIEF_DEMO)**：好奇猫悄悄摸上高台，伸爪**试探轻推一次**看杯子晃动并扭头观察人类反应，随后大力反手抽击将水杯砸碎打翻成水洼！
  - 💖 **心机碰瓷与肚皮陷阱 (BELLY_TRAP)**：粘人猫预判人类鼠标轨迹，啪嗒侧躺露出柔软白肚皮假意求摸；抚摸超过安全时间立即发动**爱情咬咬暴击 (Love Bite)** 并蹬腿弹射逃跑！
  - ☀️ **逐日朝圣 (SUNBEAM_PILGRIM)**：巡游大平层追随随白昼慢移的阳光光斑，踩平地铺舒服融化为一滩金黄液体。
  - ⚡ **战术三维立体跑酷 (PARKOUR_CIRCUIT)**：拒绝平面撞墙，沿地板->纸箱->跳台->高台规划立体航线，终点急停侧滑并淡定舔毛。
  - 🏷️ **猫生战术意图浮动徽章 (Tactical Intent Floating Badge)**：猫咪头顶优雅显示当前大计徽章（如 `[ 👑 争霸王座 ]`、`[ 🎯 战术潜行 ]`、`[ 🥣 敲碗催粮 ]` 等），让玩家一眼洞悉猫咪的战略心机！
- **💦 避水本能与湿爪狂暴甩水 (Puddle Avoidance & Wet Shake)**：
  - 遇到地面水洼大跨步起跳跨越；
  - 踩中水洼立刻三足立地，悬空一只湿爪以 25Hz 高频抽搐甩水，飞溅细微水滴粒子并面露极度嫌弃！
- **真实生理驱动循环 (Drive Engine)**：
  - 饥饿度持续代谢衰减，低饥饿时满屋嗅闻觅食。
  - 精力耗散与无聊值积攒，当精力充沛且无聊值高时爆发 **3AM Zoomies（夜半发疯跑酷）**，在地面与跳台间暴冲反弹！
  - **激光捕食挫败感 (Laser Frustration)**：连续扑空积累挫败甩尾抱怨，抓到实体玩具（毛线或鱼干）才能解压释放！
- **真实猫体形态动力学 (Liquid & Poses)**：
  - 🍞 **母鸡蹲 (Loafing)**：把四只小肉垫收进胸腔下方，变成圆滚滚的面包块，伴随呼吸均匀起伏。
  - 🌊 **长条液体猫拉伸 (Long Cat)**：提抓后颈皮时，身体沿重力纵向拉伸 1.6 倍，四爪软绵绵悬空垂荡，眼神呆滞无辜。
  - 🌿 **猫薄荷极乐 (Catnip High)**：四脚朝天仰面打滚，双后腿高频狂踹“兔子蹬 (Bunny kick)”。
- **经典猫生本能与多猫社交网络**：
  - 😏 **高台贱爪推物 (Knocking things off)**：跳台或窗台上的猫，发现边缘有毛线球时，会停步凝视并伸爪一点点推下悬崖看它自由落体！
  - 🐦 **窗台飞鸟嗑牙声 (Chattering)**：凝视窗外掠过的飞鸟时，下颚高频微颤，发出真实的捕食拟态齿颤声。
  - 🌸 **碰鼻礼 (Nose Bump)**：两猫正面相遇碰鼻轻嗅打招呼，增进好感。
  - 💥 **互相舔毛转互扇 (Allogrooming to Cat Slap)**：帮对方舔毛超过 3 次触发感官过载，两猫腾空互扇喵喵拳并弹开！
- **6 大性格真实决策倾向矩阵**：
  - 贪吃鬼（嗅觉半径 2 倍）、跑酷狂人（Zoomies 率高）、佛系咸鱼（常年母鸡蹲）、超级粘人（寸步不离跟随鼠标手）、好奇宝宝（推物狂热）。

### 2. 🪑 具有刚体碰撞与联动的家具与玩具 (`js/furniture.js`, `js/toys.js`)
- 🤖 **智能扫地机 (Roomba)**：巡航时具备物理推力，把挡路的毛线球、纸箱撞飞推走；猫咪可骑乘巡航领地。
- 📦 **纸箱 (Cardboard Box)**：大橘和英短（胖猫）钻入时会卡住半截屁股扭动挤入；受刺激时猫咪顶着箱子满地滑行（猫猫装甲车）！
- 🧶 **毛线球 (Yarn Ball)**：扑咬时逐渐散落线头节段，体积微缩；猫咪踩上散线有几率触发缠爪甩腿！
- ☀️ **阳光光斑 (Sunbeam)**：随日照缓慢漂移，打盹猫咪半梦半醒追光挪移。
- 🪟 **景观大窗台 (WindowSill)**：窗外小鸟定时飞过鸣叫，吸引猫咪聚拢抬头观鸟。

### 3. 🔊 纯合成 Web Audio 声音引擎 (`js/audio.js`)
- **零外部音频文件**：纯粹使用振荡器、带通/低通滤波器与噪声发生器实时合成！
- **拟真猫咪呼噜声（Purr Engine）**：基于 25Hz 低频调制粉红噪声，还原猫咪喉部共振。
- **多样化猫鸣**：轻柔短促的鸟鸣颤音（Chirp）、撒娇拉长音（Pleading）、捕食咔咔齿音（Chatter）。
- **程序化生成 Lofi 氛围音律**：五声音阶和弦进行，陪伴学习/工作的舒缓背景音乐。
- **物理碰撞与器械音**：磨爪摩擦声、吃鱼咀嚼脆响、扫地机马达嗡鸣、相机机械快门声。

  - 倒计时引导游戏，操作红点带领猫群扑击金色星星，挑战高分！
- 💾 **本地自动存档**：自动持久化保存当前猫咪成员、名字、性格与装扮。

## 📁 项目工程架构

```text
cyber-meow-sandbox/
├── index.html            # 主界面与 DOM 结构（单文件即开即玩）
├── start.bat             # Windows 一键启动脚本
├── server.py             # 极速本地 Python 开发服务器
├── README.md             # 详细文档
├── css/
│   └── style.css         # 赛博拟物玻璃拟态（Glassmorphism）样式
├── js/
│   ├── physics.js        # Verlet 链式物理、向量数学与世界环境控制
│   ├── audio.js          # Web Audio 声音合成器（呼噜、猫叫、Lofi生成乐）
│   ├── furniture.js      # 扫地机、猫爬架、猫抓板、纸箱、阳光光斑
│   ├── toys.js           # 逗猫棒、毛线球、小鱼干
│   ├── cat.js            # 猫咪智能体（骨骼动画、表情IK、行为树）
│   ├── environment.js    # 日夜主题、雨滴与微尘萤火虫天气
│   ├── ui.js             # 身份证、拍立得快照、挑战小游戏
│   └── app.js            # 核心游戏循环、输入监听与状态协调
└── tests/
    └── verify.js         # 自动化语法与物理逻辑自检测试
```

## 🚀 启动与体验方式

### 方式 A：直接运行（推荐，秒开）
- 双击运行根目录下的 [start.bat](file:///f:/PlayGround/cyber-meow-sandbox/start.bat)。
- 或者直接用 Chrome / Edge / Firefox 双击打开 [index.html](file:///f:/PlayGround/cyber-meow-sandbox/index.html)。

### 方式 B：启动本地 Python HTTP 服务
```powershell
python cyber-meow-sandbox/server.py
```
终端会自动弹出 `http://localhost:8088`，亦可分享给同一局域网下的手机或平板浏览器体验！

### 方式 C：运行自动化测试
```powershell
node cyber-meow-sandbox/tests/verify.js
```
