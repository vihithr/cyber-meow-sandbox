# ADR-001：语义轴、未来需求与性能架构取向

- **状态**：accepted
- **日期**：2026-11-20
- **决策者**：项目负责人授权由工程代理独立裁决语义层（原报告中列为「需团队协商」的待裁决项，本次授权关闭该项）
- **适用对象**：`cyber-meow-sandbox`（8 个 IIFE 模块、`window.CyberMeow` 全局命名空间、零依赖、支持 `file://`）

## Context

`docs/ARCHITECTURE_REVIEW.md` 的裁决把三项留给团队协商：层语义轴选定、C2 的 δ/N 阈值、`sceneContext` 的契约地位。项目负责人明确表示没有既定需求想法，授权工程代理独立负责语义层，并要求预测未来功能与需求、据此确定性能所需架构并实施优化。

本 ADR 只关闭「语义轴」与「未来需求取向」两项。C2 阈值仍保持 Unknown：项目仅 14 次提交、跨度 2 天且含大爆炸提交，样本不足以支撑阈值-持续判定；伪造数据比留空更有害。

## 未来需求预测

预测以现行功能边界为锚：10 大议程、11 类家具、6 类玩具、40/80/60 实体上限、6 字段存档。判断依据是「现有约束最先被哪一项新需求撑破」，而非罗列愿望清单。

| 预测需求 | 触发信号（当前约束） | 对架构的真实压力 |
|---|---|---|
| 多场景／房间切换 | 当前硬编码单座 3000px 世界 | 世界状态与实体解耦；重建时须释放缓存与引用 |
| 存档扩展（位置／家具布局／成就） | 当前只存 6 个标量字段、无版本号 | 需要稳定的序列化契约与迁移规则 |
| 实体规模增长 | 当前上限 40/80/60，传感器每帧全扫 | 范围查询需要空间索引，而非继续线性扫描 |
| 触摸端适配 | 已支持部分 pointer 事件，`getWorldPos` 刚修复 0 坐标 bug | 输入层契约统一；命中判定与坐标系保持一致 |
| 任务／剧情系统 | 现有 10 大议程是自发行为，无外部目标注入 | 需要目标注入契约，且不能破坏现有状态机优先级 |

这些需求共同指向三个架构着力点：**状态可序列化**、**范围查询可扩展**、**跨模块写入可审计**。它们全部落在表示层或协商层，按 theory.md §8 不产生 T1 结构裁决。

## Decision

### 1. 语义轴定为认知分组，不作为依赖方向约束

专家团已机械判定六节点 SCC `{app, cat, furniture, toys, environment, ui}` 为诚实耦合，`physics`/`audio` 为出度 0 源点，商图无环。强行单向化会制造伪独立（S5：伪独立比真耦合昂贵）。因此语义轴只用于理解与归档，不新增任何依赖边：

| 认知层 | 模块 | 语义范围 |
|---|---|---|
| L0 能力层 | `physics.js`、`audio.js` | 无项目语义的纯能力：数学、物理常量、声音合成 |
| L1 领域对象层 | `furniture.js`、`toys.js`、`cat.js` | 世界中的对象及其自主行为 |
| L2 世界状态层 | `environment.js` | 主题、天气、粒子、飞鸟等环境状态 |
| L3 编排层 | `app.js` | 组合根：相机、主循环、`sceneContext`、实体生命周期 |
| L4 交互层 | `ui.js` | 输入、弹窗、HUD、挑战、快照 |

该分层与依赖图**不对齐**：`cat.js` 通过 `sceneContext` 读写 `app.js` 状态，`ui.js` 直接读猫字段。这是被 S5 接受的实情，不是待修缺陷。

### 2. 性能优化需要的架构取向

在「不拆 cat.js、不造新层、维持六节点环」的前提下，性能工作限定为四项：

1. **帧率一致性**：物理积分统一从 `sceneContext.dt` 推导步长，阻尼按 `Math.pow(阻尼, step)` 缩放。这是行为正确性前提，也是未来做确定性回放的前置。
2. **缓存生命周期受控**：缓存 key 只由静态量构成；为 Map 设容量上限作为防御。泄漏来自 key 设计，不是缓存本身。
3. **逃逸可审计**：已观测的跨模块字段写入补 `@escape H4` 标记，保留「故意例外」与「意外耦合」的可区分性（D3/H4），不封死字段。
4. **裁决可证伪**：把上述约束写成机械门禁，并为每个门禁配反例（反模式 #7）。

### 3. 明确不做

拆散 `app.js` 组合根、以过载为由的垂直层级分解、引入 ECS/通用组件框架、为假想漂移封死全部字段。理由分别对应反模式 #1、D2 禁止操作、theory.md §8 与 S5、D3/S3。

## Consequences

- 六节点 SCC 保持不变；`cat.js` 不拆分；不新增层。架构裁决的 Finding 1/3/4/5 结论维持原状。
- 未来若做多场景或空间索引，应作为**表示层决策**引入，用 `tests/bench.js` 与真机 profiler 论证收益，不申请 T1 结构背书。
- `@escape H4` 只是标记，不改变运行时行为；标记数量是有限的、可枚举的。
- C2 的 δ/N 与 `sceneContext` 契约地位仍未裁决，留待足够历史数据或明确的产品需求。

## Verification

```powershell
cd F:\PlayGround\cyber-meow-sandbox
node tests/verify.js     # 93 项断言，含 tests/architecture.js 的 7 项架构门禁与 2 项反例
```

架构门禁检查契约面可枚举、H4 标记完整、bridge 类型字符串一致、渐变 key 无动态 `toFixed`、物理积分走 `frameStep(sceneContext)`。每个守卫都注入违规写法验证其会失败；无反例的守卫视作无效。
